# إشعارات قرارات طلبات العقارات والخدمات

يستدعي مسارا قبول الطلب وإرجاعه للتعديل تكامل تقنيات الحالي بعد نجاح معاملة
حفظ الحالة والنشر. فشل تقنيات أو غياب الإعدادات لا يلغي قرار الإدارة.
الإرسال المقبول من البوابة لا يعني تأكيد وصول الرسالة للجوال.

## إعداد الإنتاج

يُستخدم المفتاح الحالي `TAQNYAT_API_KEY` دون نسخة جديدة منه.
أضف أسماء **القوالب المعتمدة فعلياً في حساب تقنيات** إلى متغيرات البيئة:

- `TAQNYAT_SUBMISSION_APPROVED_TEMPLATE`: اسم قالب قبول الطلب.
- `TAQNYAT_SUBMISSION_REVISION_TEMPLATE`: اسم قالب الإرجاع للتعديل.
- `TAQNYAT_SUBMISSION_TEMPLATE_LANGUAGE`: رمز لغة القالب، الافتراضي `ar`.

لا توجد أسماء قوالب افتراضية مفترضة، ولا يُستخدم قالب رمز التحقق لإرسال
إشعارات الطلبات. يجب اعتماد القالبين لدى تقنيات/واتساب قبل تفعيل الإرسال.

### نص قالب القبول المقترح

أهلاً بك شريكنا العزيز {{1}}، تم قبول طلب إضافة ({{2}}) ونشره بنجاح على منصة
تكية (takyeh.sa). نتمنى لك تجربة موفقة!

متغيرات متن القالب بالترتيب: اسم المالك، اسم العقار أو الخدمة.

### نص قالب الإرجاع المقترح

أهلاً بك شريكنا العزيز {{1}}، تم إرجاع طلب إضافة ({{2}}) للتعديل.
الملاحظات: {{3}}. نرجو الدخول للوحة التحكم وتحديث البيانات لإعادة المراجعة.

متغيرات متن القالب بالترتيب: اسم المالك، اسم العقار أو الخدمة، ملاحظات المدير.
استخدم قالباً بمتن فقط، دون متغيرات إضافية في ترويسة أو أزرار.

## سلوك التشغيل

- يُحل اسم المالك وجواله عبر هوية حسابه المرتبطة، لا عبر بريد قابل للتغيير.
- عند غياب ملف المالك يُستخدم رقم واتساب الطلب والتحية العامة.
- تُطبّع الأرقام العربية والفارسية والمحلية إلى `9665xxxxxxxx`.
- لا تتكرر رسالة القبول عند إعادة حفظ الحالة نفسها، ولا رسالة الإرجاع عند
  إعادة حفظ الملاحظات نفسها. تغيير ملاحظات الإرجاع يرسل تحديثاً جديداً.
- لا تُرسل رسائل لحالات الانتظار أو الرفض.
- تُسجل أسباب الفشل المختصرة دون رقم الجوال أو نص الملاحظات أو مفاتيح الربط.
- لا توجد إعادة محاولة تلقائية؛ فشل الإرسال لا يستدعي إعادة حفظ القرار.
- الاختبارات تحاكي تقنيات؛ لا ترسل رسائل حقيقية إلى ملاك المنصة.
