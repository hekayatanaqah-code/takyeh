---
name: Section guide identifiers
description: Preserve saved help videos when synchronizing the admin guide list with owner-facing tabs.
---

Section-guide identifiers are persisted with uploaded or linked videos. Do not rename a guide key just to match a tab ID or revised Arabic label; change the display label instead, and add an explicit new key for a genuinely new tab.

**Why:** Some finance tabs use different navigation IDs from the historical guide identifiers. Renaming the identifier would leave existing videos saved but invisible in the owner's guide button.

**How to apply:** When changing the owner navigation or admin guide catalog, compare the admin keys with the actual owner guide entry points and preserve existing associations.
