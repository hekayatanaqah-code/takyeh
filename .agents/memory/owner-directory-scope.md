---
name: Owner directory scope
description: Registered owners must be visible before adding or publishing any business inventory.
---

إدارة الملاك تشمل جميع حسابات الملاك المسجلة حتى قبل إضافة عقار أو خدمة، مع إمكانية متابعة هؤلاء الملاك بالجوال وواتساب، وإجمالي يعكس الحسابات المسجلة فعلياً.

**Why:** المستخدم طلب متابعة من سجّل ولم يُكمل إضافة نشاطه؛ الاقتصار على أصحاب الأنشطة المنشورة يُخفي هذه الحسابات عن فريق الإدارة.

**How to apply:** اجعل التسجيل أساس القائمة والعداد، وليس اعتماد العقار أو الخدمة أو وجود منحة اشتراك. ميّز بين مالك لم يضف نشاطاً أصلًا ومالك أضاف نشاطاً لم يُعتمد بعد؛ عدم الاعتماد وحده لا يعني عدم إضافة نشاط.
