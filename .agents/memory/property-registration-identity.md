---
name: Property registration identity
description: Business meaning of duplicate property identity versus a similar name.
---

Treat a property name as a blocking duplicate only when its city and district also match; category is not part of that identity. The same name in the same city but a different district is allowed with a friendly advisory. A previously registered property WhatsApp number blocks registration, including equivalent local/international and Arabic-digit formats.

**Why:** The user explicitly requested these distinctions for the owner registration wizard. The previous name/city/category rule would wrongly reject properties in different districts.

**How to apply:** Keep early registration checks and final submission checks consistent. Do not later restore city-wide name uniqueness or make changing the property category a way around identity checks.
