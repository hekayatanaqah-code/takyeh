---
name: Administrative amenity labels
description: Arabic-only facility names in administrative property and submission details.
---

Administrative property and submission details must use the same managed Arabic amenity names shown to owners, never UUIDs, technical keys or long English identifiers.

**Why:** The user explicitly requires Arabic facility names in the administration review screens.

**How to apply:** Resolve display labels from the catalog, including inactive facilities retained for historical requests. Keep stored identifiers intact; an unavailable name should have an honest Arabic placeholder, not an invented translation. Reviewers may read catalog names without receiving catalog-editing permissions. Keep this presentation change separate from owner-facing behavior.
