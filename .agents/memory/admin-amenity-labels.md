---
name: Arabic amenity labels
description: Arabic-only facility names in administrative details and public property search cards.
---

Administrative property and submission details and public property search cards must use managed Arabic amenity names, never UUIDs, technical keys or long English identifiers.

**Why:** The user explicitly requires Arabic facility names in both administration review screens and public property search cards.

**How to apply:** Resolve display labels from the catalog; administration can also read inactive facilities retained for historical requests. Keep stored identifiers intact; an unavailable name should have an honest Arabic placeholder, not an invented translation. Reviewers may read catalog names without receiving catalog-editing permissions. Preserve existing owner editing and registration behavior when hardening these display surfaces.
